# Recorded sentences

Drop one recording per sentence in this folder, named:

    item01.mp3, item02.mp3, ... item20.mp3

The screener plays a recording when it finds one. If a file is missing, it falls back to the device's built-in reading voice, so you can add recordings a few at a time.

Tips: record in a quiet room, leave about half a second of silence at the start and end, and export as MP3 (most phones and Audacity can do this).
